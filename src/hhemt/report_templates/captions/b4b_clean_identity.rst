Raw byte-for-byte identity over time, across clean compute configs.

Per-timestep binary identity of the raw TRITON output rasters (``out_triton/bin`` water-level / max-water-level grids) across this master's clean (``n_resumes == 0``) compute-config sub-analyses. Comparisons are WITHIN a hardware family against that family's own reference, because BIT4BIT is a double-precision serial-oracle property and a GPU raster is never bit-identical to a CPU one — a single cross-family reference would make this a magnitude view rather than an identity view. There are exactly TWO families: **CPU**, referenced to the serial-CPU config; and **GPU**, referenced to one deterministically-selected GPU device (the ensemble partition sorts alphabetically, then sa_id, so the starred row does not move between renders of the same data). One GPU reference rather than one per GPU hardware is what makes "GPU results do not vary across hardware" a TESTABLE claim: a differing cell in the GPU panel now means one GPU hardware diverged from the other, which the retired per-hardware split could not express. Green cells are byte-identical to their family reference at that reporting timestep; crimson cells differ. This is a clean-vs-clean comparison (no resume boundaries). A ``passed = False`` verdict with differing cells is EXPECTED where the clean configs span backends (GPU vs CPU raw rasters are not bit-identical — BIT4BIT is a double-precision serial-oracle property) or rank counts; the verdict summary discloses the differing-cell denominator and cause. This is cross-config divergence, NOT resume-induced. The resume-validity comparison is not in this report: the clean and resume arms run as sibling masters, so no within-master figure can pair them, and the claim is delivered on the cross-experiment (combined) report as ``cross_experiment_intercomparison`` for the scalar clean-vs-resume identity table and ``cross_experiment_intercomparison_maps`` for the spatial resume-minus-clean difference. Reads ``eda/b4b_clean_identity.zarr``; renders an honest-degradation panel when that backing artifact is absent or degraded.
