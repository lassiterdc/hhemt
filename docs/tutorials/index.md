# Tutorials

Install the toolkit with the [Installation](../how-to/installation.md) guide before any tutorial.

- [Simulating an event ensemble](norfolk-observed-events.md) covers storms that happened on the Norfolk case study with the TRITON, TRITON-SWMM, and SWMM models, selecting the events by key from the observed-event index.
- [Running a benchmarking experiment](norfolk-compute-config-sweep.md) compares compute configurations for one storm and gives the core count for a simulation along with the evidence and limits behind the choice.
- [Running a simulation interactively in Python](interactive-python.ipynb) gives the calls that run the Norfolk example from a Python session, then opens a committed example result and plots the difference between the models.
- [Exploratory analysis of an event ensemble](exploratory-analysis.md) runs `hhemt eda` on the observed-event result and draws the difference between the models from the committed example result.

The event-ensemble and benchmarking tutorials link the full report of the experiment and show a representative figure from the report. A single task has a guide under [How-To Guides](../how-to/index.md).
